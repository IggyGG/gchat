# Fixedsys Excelsior

`fixedsys-excelsior.ttf` is the unmodified `FSEX302.ttf` asset from
[kika/fixedsys v3.09.10](https://github.com/kika/fixedsys/releases/tag/v3.09.10).
Originally authored by Darien Valentine; this derivative is maintained by
Kirill Pertsev. This is a Unicode TrueType recreation of classic Fixedsys,
not the original Windows bitmap font. The intended size is 16 CSS pixels.

Source: https://github.com/kika/fixedsys

SHA-256: `842f8fbf80f57d867aeb1d2988140d3ea8b4718e5f687035b0a3b66756df3899`
